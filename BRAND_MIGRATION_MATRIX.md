# ClassMatter brand and compatibility matrix

Public brand: **班事有谱 · ClassMatter**. Formerly Class OS / class-teacher-workbench. The new GitHub name is a plan, not an existing or authorized public remote.

| Surface | Status | Reason / validation |
|---|---|---|
| README/EN, contribution/security/agent guide, doc navigation | CHANGED | New brand and synthetic-only limits; no private source ledger |
| Runtime, demo sidebar, headings, assistant label and fallback title | CHANGED | Display only; original browser flows retained |
| HTML title, meta description, site metadata | CHANGED | Static new title, no external images/telemetry |
| Vite editor integration | CHANGED | Standard React/Tailwind; loopback and no source maps; original Web/browser regression required |
| Web package | CHANGED | `@classmatter/web`, same dependencies; normal lockfile regeneration and frozen install |
| Backend CLI help | CHANGED | Display description only; command names/options unchanged |
| CI/report names | CHANGED | Synthetic checks only; no release authority |
| `class_os` / `class-os-backend` | PRESERVED_FOR_COMPATIBILITY | Imports and operator package-version diagnostics depend on them; no user branding mandate for internal distribution |
| `class-os.*`, `class-os-r1`, `CLASS_OS_*`, tool IDs/routes | PRESERVED_FOR_COMPATIBILITY | Stable serialized/configured contracts; no migration implied |
| DB schema/tables/roles, head0015→0016 migrations | PRESERVED_FOR_COMPATIBILITY | Historical migration bytes and explicit upgrade tests protected |
| `.ai/gates/`, eval IDs, task source rows/hashes | PRESERVED_FOR_COMPATIBILITY | Byte-for-byte protected; formal state not promoted |
| `docs/specs/class-os-v1/`, frozen atomic-task table wording | PRESERVED_FOR_COMPATIBILITY | Paths and full rows are used by verifiers; historical technical words are not new public marketing |
| Synthetic-policy authorization record path | PRESERVED_FOR_COMPATIBILITY | Fixed verifier anchor; content replaced with non-identifying technical summary, not original instructions |
| Local-runtime path, backups, DPAPI | PRESERVED_FOR_COMPATIBILITY | Never touch user instances, credentials or stored data for branding |
| Original Git history and remote URL | DEFERRED_WITH_REASON | Private source untouched; candidate inherits none, no push configured |
| New Python distribution name | DEFERRED_WITH_REASON | No functional benefit without package/version diagnostic migration; preserve lock and runtime behavior |
| Logo and screenshot set | DEFERRED_WITH_REASON | Text brand is sufficient; no unreviewed visual assets published |

Remaining technical old-name occurrences are enumerated in `PUBLIC_BRAND_INVENTORY.json` by path, category and count, not silently globally replaced; old display brand source paths are0. Root Apache-2.0/Gdnbit attribution and redistribution rights were separately confirmed, not inferred from renaming. Audited bytes survive Windows-style checkout conversion through a byte-preserving default plus explicit original LF fixture/validator rules; no legacy encoding migration is performed. Future technical renaming needs explicit compatibility tests.
