# ClassMatter third-party notices

Project-owned code uses Apache-2.0, Copyright 2026 Gdnbit. The owner confirms redistribution rights for project/prototype code. This is an ownership assertion, not an independent legal clearance; dependency components retain their own licenses and notices.

Dependencies are installed from frozen lockfiles, not vendored executable binaries. Exact installed-package license metadata and copied upstream license texts are inventoried under `third_party/` when generated. Public upstream copyright holders must retain their notices; do not anonymize legal attribution.

Important components: React/Vite/Tailwind/Lucide (generally permissive), Pydantic AI (MIT), FastAPI/SQLAlchemy/Alembic (MIT), OpenAI SDK (Apache-2.0), Psycopg (LGPL-3.0), and signature-spike cryptography/in-toto components. These descriptions are orientation, not a complete transitive-license verdict. The generated inventory is authoritative for exact installed versions and available notices; unknown/missing terms require review.

The optional configured Gemini path uses Pydantic AI's Google extra and the official Google Gen AI SDK (Apache-2.0). Its locked dependencies retain their own Apache/BSD and cryptography dual-license terms. Exact versions and original notices are included in the backend inventory; adding this source dependency is not permission to activate a Provider or a packaged-binary license verdict.

Editable composer imports and saved-document Office exports use python-docx/openpyxl/python-pptx (MIT), defusedxml (PSFL), et-xmlfile (MIT), lxml (BSD-3-Clause), Pillow (MIT-CMU) and XlsxWriter (BSD-2-Clause). The exact eight locked versions and original installed notices are retained in the backend inventory. These packages are installed dependencies, not redistributed Office binaries; workbook formulas are read as text, never executed. Text-only DOCX/PPTX derivatives reuse the existing pinned python-docx1.2.0 and python-pptx1.0.2; they do not bundle Office, fonts or external image/model services.

Markdown presentation in those derivatives uses markdown-it-py4.2.0 and mdurl0.1.2 (MIT). All three original installed license texts, including markdown-it and Joyent attribution, are retained with checksums in the backend inventory. The parser consumes CommonMark tokens; it does not render executable HTML or fetch link/image resources. Source: [markdown-it-py4.2.0](https://github.com/executablebooks/markdown-it-py/releases/tag/v4.2.0).

Read-only Web document previews use pinned react-markdown10.1.0 and remark-gfm4.0.1 (MIT), resolved with their transitive packages in the Web lockfile. The existing desktop notice collector must retain the exact installed Web production closure, including these packages' original notices. The older static Web inventory predates this addition and is not evidence for the new closure. Source: [react-markdown](https://github.com/remarkjs/react-markdown), [remark-gfm](https://github.com/remarkjs/remark-gfm). This renderer does not enable raw HTML, executable plugins or automatic image retrieval; canonical Markdown remains editable source.

The installed scope also includes MPL-2.0 components such as certifi/pathspec, and PSF/BSD/ISC terms. No such dependency is relabeled Apache-2.0. Some wheels omit notices: exact-tag upstream notices supplement logfire-api and the native Rolldown binding; source URLs and checksums are in `third_party/supplemental-license-review.json`. `review_required=[]` means the installed metadata/notice collection has no unresolved entry, not universal distribution-law approval.

Psycopg binary wheels can include native libpq/OpenSSL/other notices; source-only distribution with separately installed dependencies is different from bundling a desktop image, container or binary. Do not claim full binary-distribution compliance from Python metadata. PostgreSQL binaries, Node, Python, browsers and scanning executables are not shipped in this candidate.

Mathematical font assets from pinned KaTeX are bundled locally, with no runtime font CDN. No personal screenshots, logos or archive exports are included. Future packaged releases require a separate binary SBOM/license and corresponding-source/notice review where applicable. Vulnerability scans and license checks are independent.

Teaching formulas in read-only Markdown use remark-math6.0.0, rehype-katex7.0.1 and KaTeX0.19.1 (MIT), with original source/copy unchanged. A reviewed pnpm override replaces the plugins' older KaTeX range to address [the upstream advisory](https://github.com/KaTeX/KaTeX/security/advisories/GHSA-238p-pmpm-9mq7); compatibility and the actual installed notice closure are checked before acceptance. The two remark-math repository packages omit license files from their npm archives; exact npm gitHead upstream license texts, source URLs and SHA-256 are recorded in the existing supplemental review. Desktop notice collection verifies exact package/version, contained path and original hash before copying; unknown or changed text still fails. This inventory is not a public binary release clearance.

The older `third_party/dependency-licenses.json` does not inventory this new build/test scope. The local bundle retains Electron's LICENSE/LICENSES.chromium.html, project notices, and generated exact installed Web production-dependency notices inside its application archive. This is a local unsigned Demo, not an approved public binary release or a complete binary-distribution compliance verdict; see [desktop boundaries](docs/desktop-demo.md).
