# Manual UX and Business Validation

## Protocol

- 至少 5 位目标班主任；若早期只能使用自愿参与的目标教师，则每个任务至少重复 5 次并明确样本限制。
- 使用目标手机和电脑，不用开发者机器代替。
- 先测现状，再测原型/实现；记录时间、步骤、错误、求助、信心和主观负担。
- 录屏、截图和笔记必须脱敏并按批准位置存储。

## Interview Questions After Each Task

1. 你认为刚才系统做了什么？
2. 哪一步让你不确定或最费力？
3. 如果系统做错，你会在哪里发现并如何恢复？
4. 哪些信息不希望 AI 或其他人看到？
5. 你愿意在真实工作中何时使用，何时仍用原方法？

## Business Value Gate

至少一条核心闭环中位时间或步骤较现状降低 30%，且错误率不升高、敏感信息暴露不增加。未通过时先改任务/交互，不以扩充功能解决。
