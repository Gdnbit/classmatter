# ClassMatter UX baseline

The React/TypeScript shell is a frozen interaction reference, not authoritative business state. Original source provenance is retained privately; redistribution rights remain subject to owner confirmation. No personal screenshots are distributed.

The actual interface is `src/runtime/R1App.tsx`; `VITE_CLASS_OS_DEMO=true` explicitly selects the mock shell. Demo students and school labels are conspicuously synthetic and generated consistently across references. No demo store, timer or candidate button supplies a production database implementation.

The public candidate replaces editor-specific Vite injection with ordinary React/Tailwind configuration, disables source maps in all modes and defaults to loopback. This removes tooling, not business flows. The fixed bottom composer, white main canvas, pale sidebar, scoped views and preview-before-commit interaction remain. Run original Web and browser tests after edits.
