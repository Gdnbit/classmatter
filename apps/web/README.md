## Commands

Settings now supports the complete explicit model-control flow: syntax-only validation → protected candidate → existing W2 preview/approval/commit → separately confirmed connectivity/tool test → enable, plus disable/remove. Default is offline; startup exact-endpoint allowlisting is required. Keys are write-only and cleared after staging/unmount/session rotation, never put in browser persistence, proposal or returned status. A delivery failure is unknown (possibly charged/effective), blocks Agent sends and requires a read-only status check, never automatic retry. Configuration changes invalidate old conversation views. The existing dev-only Ajv compiler generates closed status/staged/syntax validators; build/typecheck detect drift. Offline SDK/real PostgreSQL/browser tests cover both protocols and the full mobile flow; no real-provider quality, fees or production admission is claimed.

```powershell
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
pnpm build
```

The default app is the synthetic R1 Web/API composition, using real ISB/QG/BCG when served by `backend/local.py serve`. Prototype stores are used only by the explicit `VITE_CLASS_OS_DEMO=true` profile; they are never persistence or authorization. Complete MVP/release acceptance is still pending. Canonical requirements and architecture are in the repository-level `docs/` and `.ai/` directories.

`src/data/*.ts` is versioned prototype source required by the build. Do not copy real student records into it. A clean Git checkout must typecheck and build without files from a developer's ignored local directories.

Identity replies use the four canonical schemas in `contracts/http/`. Ajv 8.17.1 is a dev-only standalone compiler; `node scripts/generate-identity.mjs` mechanically regenerates the trusted CJS validator, while dev/build/typecheck check drift. Browser code never compiles user schemas or uses eval; only the small generated validators/helpers are bundled. No coercion/defaults/removing fields, and kit selectors must be unique. Unknown mutation outcomes clear private UI state and offer a GET session probe, never automatic login/reissue/logout retries or plaintext-kit replay. A usable session does not prove the preceding operation completed. `node --test tests/identity.mjs` tests compiled client code; actual PostgreSQL/browser failures are covered by `backend/tests/test_web.py`.
