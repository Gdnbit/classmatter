# 前端 Demo 定向修复与验收

日期：2026-10-22。范围：当前 Web Demo 与 Windows x64 桌面宿主。它不是完整产品/真实 Agent/R1 的最终验收，也不把模拟实现升级为业务事实源。

## 实施边界与代码地图

- `apps/web/src/demo/seat-plan.ts`：仅演示交换的明确语法、纯函数候选与投影校验。它不是自然语言理解、排座算法或生产 Command Gateway。
- `state/TransactionSessionProvider.tsx`：按对话隔离的演示事务；只有明确确认入口才能应用当前快照，应用只到 MockDomainStore 内存；不制造服务器回执。
- `store/ConversationStore.tsx`：真实的内存会话、标题、消息、未发送草稿；不把它变成正式事实或长期画像。
- `store/DemoWorkStore.tsx`：合成事项及一致的详情/计数。来源不是学校指令，演示状态不证明实际履职或组织接手。
- `store/UiFeedbackStore.tsx`、Sidebar/Composer、`desktop.css`/`acceptance.css`：弹层安全区、焦点、菜单、布局和反馈。
- `apps/desktop/tests/acceptance.cjs`：真实打包进程里的点击、输入、模拟确认、跨页检查及截图；无业务 API/模型/数据库。

没有新增依赖或后端接口，不修改Schema、QG/BCG/ISB、安全策略或MCP权限。没有将真实文件、本机FS、任意shell、生产数据或实际提醒接入桌面。现有Electron沙箱、固定菜单桥、外部请求拒绝仍保留。

## 复验

按[桌面运行说明](../apps/desktop/README.md)安装冻结依赖，关闭已运行的 Demo，然后执行：

```powershell
# apps/web
pnpm typecheck
pnpm build
# repository root, Windows x64 / PowerShell 7
./scripts/verify.ps1 -Suite desktop
./scripts/verify.ps1 -Suite docs
./scripts/verify.ps1 -Suite gate-graph
./scripts/verify.ps1 -Suite task-graph
```

桌面 suite 包含7项资源/桥接单测、普通打包窗口回归和A01—A11定向验收。Web typecheck现在共37项测试（原32项加5项演示座位测试）并运行TypeScript检查。通过的桌面定向测试要求 `pageErrors=[]`、`externalRequests=[]`；不存在真实模型质量或后台服务可用性的推断。

结果与截图生成在 `apps/desktop/.build/evidence/acceptance/`，不进入Git。最小窗口菜单、抽屉安全区和准确预览已用实际截图检查；原生窗口控件不包含在renderer截图内，其overlay与生命周期由原桌面回归另测。此证据不是完整WCAG、读屏器、多显示器DPI或真实老师净负担验证。完整后端/数据库回归不是本次前端变更的验收范围。

## 明确保留的限制

- Demo语法只支持明确两名合成学生交换座位；否定、条件式、未知学生、附加条件、重复对象与模糊请求拒绝生成。该限制是安全且诚实的离线演示，不宣称拥有完整Agent自然语言能力。
- 刷新/退出重置内存；会话草稿只是本次运行内保留，不是跨设备同步、业务持久化或数据库恢复。附件尚不按会话持久化，切换会话会清除选中附件。
- 文件选择/拖拽只演示本地选择，不读取压缩包/PDF/Office内容、不OCR、不上传；单次一个附件，多附件明确拒绝。
- 模型、ASR、真实录音、自动化调度、报告/导出和真实组织协作仍未接通；演示提示不能当作正式执行回执。
- 流式输出、真实工具调用状态/取消/失败恢复、复杂富文本/Artifact并排编辑、全局跨实体搜索与完整快捷键体系仍需独立实施和验收，不因本次优化提前宣称完成。
- 历史边界按钮禁用、原生菜单/Snap手感、多显示器、全部深层空/错/离线态和真实用户可用性仍需后续专项覆盖。未增加终端、Git/PR、多Agent控制台或完整ERP。
