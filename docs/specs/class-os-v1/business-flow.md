# Business Flows: ClassMatter v1

> 文档状态（2026-10-08）：现行规格/规划/规则；设计存在；实现/批准须另凭目标版本证据。项目完成度见 [公开工程边界说明](../../ENGINEERING_OVERVIEW.md)；本标识不提升批准、测试或任务状态。

适用性（2026-10-07）：本文含完整 v1 流程。R1 仅执行 §1/2 的手工 roster/事实/简单 Task、Today/Timeline、§10 适用运维子集与 Agent 查询/内存草稿；§3—9 不整体进入 R1。正式范围以 release-1-manifest 为准，默认 Conversation + Attention-first 不影响直接 UI 独立可用。

责任辅助理解、个人安排和组织责任分开：AI 可提取动作/声称角色/期限/依据与疑问，个人标记不代表他人接受交接。通知→责任候选→注意力转移是冻结 UX Demo 与发现方向，不新增 R1 通知/责任聚合或主动提醒。

## 1. 首次启用

```text
注册/登录 → 创建工作空间 → 创建班级/学期
→ Release 1 手工添加学生（文件导入为后续流程）
→ 配置最小字段和隐私选项
→ 完成样例演练 → 进入 Today
```

异常：邀请无效、重复班级、无稳定学生编号、导入中断、学校政策未确认。真实数据准入未通过时只允许合成数据。

## 2. 手机快速记录与跟进

```text
Today 快速记录
→ 搜索并选择学生
→ 选择事件类型 + 事实描述
→ Release 1 仅键盘/系统输入法文本（无录音、转写或附件入口）
→ 隐私与字段校验
→ 保存事件
→ 建议/创建跟进任务
→ 学生时间线和 Today 更新
```

规则：AI 推断与事实分开；Release 1 弱网只保留页面内存，不持久化 D2+ 草稿，不做无提示自动冲突覆盖。任何无法证明为本地离线的系统转写都属于外部处理器，Release 1 不提供此入口。

## 3. 名单/成绩导入

```text
上传到隔离区 → 恶意/资源检查 → 识别工作表与表头
→ 选择/复用映射 → 规范化值 → 匹配学生
→ 业务校验 → 预览新增/修改/冲突/错误
→ 用户修正或排除 → 确认批次与影响
→ 幂等事务提交 → 重算派生指标 → 审计和导入报告
```

停止：样例未确认、排名口径未知、学生身份冲突无法消解、文件含不支持宏/加密、预览版本过期。

## 4. 成绩分析与 Agent 追问

```text
选择学生/班级/考试范围 → 确定性统计服务计算
→ 结果带口径和证据 → Agent 仅基于结果解释
→ 教师追问 → 必要时追加只读 Tool
→ 生成关注项/任务草案 → 教师决定是否保存
```

禁止：由模型重新计算排名；把相关性写成原因；数据不足时生成持续趋势；自动写入永久评价标签。

## 5. 约束排座

```text
读取当前布局/学生/已有分配
→ 教师输入硬约束与软目标
→ 规范化/冲突检查
→ 求解器生成多个候选
→ 校验器独立复核硬约束
→ SeatMap + 评分 + 未满足项
→ 教师手动调整/重算
→ 差异预览 → 批准 → 版本检查 → 提交
→ 历史/审计/导出
```

不可行时只返回冲突集合和调整建议，不提供可应用按钮。

## 6. 宿舍分配/交换

```text
读取 DormMap 和有效分配
→ 选择分配/移动/交换
→ 检查容量、唯一占用和配置规则
→ 差异预览 + 生效时间 + 原因
→ 批准 → 乐观锁/幂等提交
→ 历史、审计和待同步记录
```

若学校另有正式宿管系统，ClassMatter 不声称已同步，除非正式集成返回成功回执。

## 7. 周报与工作留痕

```text
选择时间/班级/范围
→ 查询结构化事件与任务
→ 确定性汇总统计
→ Agent 组织草稿
→ 事实引用/敏感字段检查
→ 教师编辑与审核
→ 保存正式版本或导出
```

报告生成、保存正式版本和外发是三个不同状态。

## 8. 家校沟通草稿

```text
选择场景和对象 → 最小化读取相关事实
→ 生成沟通草稿 → 事实/建议/敏感字段检查
→ 教师修改 → 复制或保存
→ 人工标记实际发送结果（v1）
```

未来集成发送通道时，必须新增接收人预览、渠道授权、发送回执、撤回/补救和独立 eval。

## 9. Agent 写操作统一流程

**Future / 非 R1 Agent 路径**：R1 Draft 卡只能进入既有可信直接 UI，模型或聊天“确认”不能替代批准。以下仅约束未来独立 release 获批后的写 Tool，不是当前 catalog。

```text
intent
→ resolve scope/identity
→ read/query tools
→ command draft
→ domain validation
→ preview(diff, risk, reversibility, data destination)
→ approval token(subject, scope, version, expiry)
→ commit(idempotency key)
→ domain event + audit
→ UI result + undo/compensation option
```

拒绝、过期、版本变化、权限变化和工具错误均返回安全失败，不自动扩大范围或反复请求批准。

## 10. 备份恢复与退役

```text
定时备份 → 加密/校验 → 异地或独立介质保存
→ 定期隔离恢复 → 数据/附件/审计一致性验证
→ 记录 RPO/RTO 证据

退役：冻结写入 → 最终导出 → 用户确认
→ 按保留策略归档/删除 → 销毁密钥/撤销授权
→ 保留必要审计与退役证明
```
